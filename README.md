# Pour toi, princesse 💌

Petit site avec un message qui défile et une musique de fond.

## Publier sur GitHub Pages

1. Crée un compte sur https://github.com puis clique sur **New repository**.
2. Donne un nom (ex. `princesse`), laisse **Public**, puis **Create repository**.
3. Clique sur **uploading an existing file**, glisse **tout le contenu** de ce dossier
   (index.html, le dossier assets, .nojekyll, README.md), puis **Commit changes**.
4. Va dans **Settings > Pages**.
5. Dans **Build and deployment**, choisis **Deploy from a branch**, branche **main**,
   dossier **/ (root)**, puis **Save**.
6. Attends 1 à 2 minutes : ton lien sera `https://TON-PSEUDO.github.io/NOM-DU-DEPOT/`.

## Modifier le texte
Ouvre `index.html` et change la liste `LINES` dans la balise `<script>`.

## Fichiers
- `index.html` : la page
- `assets/bg.jpg` : image de fond
- `assets/music.mp3` : musique
